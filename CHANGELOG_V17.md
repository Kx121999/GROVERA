# GOLDEN ROOTS V17 — Smart Storefront Engine

## Implemented
- Canonical `catalog.json` product database used across the standalone site.
- Resilient loader with local-file fallback for direct previews.
- Bilingual Arabic/English search scoring, synonyms, SKU search and recent-search history.
- Multi-filter collection flow: category, availability, brand, price range and sorting.
- Cart Engine V2 with variants, quantity editing, saved cart and a test discount code path.
- Three-step checkout simulation: contact → UAE address → payment choice.
- Order confirmation page and local order history with reorder.
- Product gallery thumbnails, fullscreen zoom, recently viewed and same-category recommendations.
- Wishlist, compare, Quick Order and Farm Lists unified around the same catalog data.
- PWA manifest, service worker, install prompt and offline fallback.
- Mobile/desktop UI pass for new V17 systems.

## Intentionally not live yet
No real payment, order submission, authentication, shipping pricing, emails, Google or Meta tracking are enabled.
