# GOLDEN ROOTS V12 — Admin Workflow

1. Create/import the product in Shopify with title, price, inventory, images/media, vendor, product type, variants, and collections.
2. Add only the optional metafields relevant to that product. Do not fill unrelated fields.
3. Leave `custom.catalog_profile` blank for automatic profile detection, or set it when the Product type is unusual.
4. Add the product to the correct live collections. Homepage catalog, mega navigation fallback, smart cart matching, search, brand pages, and related commerce surfaces then update from Shopify data.
5. Set UAE shipping rates/profiles in Shopify Admin. V12 ETA text is guidance only and never overrides checkout rates.

For a 700-product catalog the intended workflow is bulk import + bulk metafield editing, not manual theme edits per product.
