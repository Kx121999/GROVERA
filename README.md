# GOLDEN ROOTS — Shopify Theme V6

Custom Shopify Online Store 2.0 theme for **GOLDEN ROOTS — جولدن روتس للزراعة ومستلزماتها**.

## V6 highlights
- Full project and storefront rebrand to GOLDEN ROOTS.
- Previous brand logo removed from all visible fallbacks and theme assets.
- Official logo remains editable through Shopify Theme Settings; a text lockup is used until it is uploaded.
- Premium mobile-first storefront, Arabic RTL and English-ready LTR.
- Mega navigation, predictive search, AJAX cart drawer, wishlist, collection filters and sticky add-to-cart.
- New **Shop by Need** section for home growing, farms, greenhouses and B2B.
- New **Quick View** modal with Shopify product JSON, variant selection and AJAX add-to-cart.
- Dynamic free-shipping progress, product recommendations and recently viewed.
- Subtle reveal motion with reduced-motion accessibility support.

## Important
No official GOLDEN ROOTS logo was supplied in this development turn, so the previous logo is deliberately not reused. Upload the approved new logo from **Theme settings → Brand → Official GOLDEN ROOTS logo**.

## GitHub Pages preview
Upload the contents of this folder to the repository root. `index.html` is already at root. This static version is a design/interaction preview; the Shopify theme is inside `shopify-theme/`.


## Official logo integration (V6)
The approved GOLDEN ROOTS green/gold logo is bundled in the theme and used automatically in the header, mobile navigation, footer, favicon/brand mark, hero brand seal and Organization structured data.
