# GOLDEN ROOTS V13 — Farm Commerce & Customer Retention

## Implemented
- Farm Quick Order Center: one-screen variant + quantity ordering with bulk AJAX add-to-cart.
- Saved Farm Lists with multiple named lists, active-list selection, bulk add-to-cart and product-level save buttons. Lists persist on the current browser/device.
- Premium customer account dashboard with Quick Order, Farm Lists, Wishlist, addresses, quote requests and saved-cart shortcuts.
- Buy Again from the latest order plus existing full-order reorder.
- Customer tier UI from customer metafield or Shopify customer tags.
- Loyalty balance UI from `customer.metafields.loyalty.points` when available. The theme does not award points itself.
- Native Shopify selling-plan selector on product pages when subscription selling plans exist.
- Request Quote Cart: sends the current cart contents through the native Shopify contact form.
- Product-card and product-page “Save to Farm List” actions.
- V12 live catalog, Smart Finder, compare, bundles, B2B MOQ, smart cart matching, media, search and all earlier commerce features retained.

## Platform boundaries
Cross-device list sync, automatic loyalty points, coupon wallets, Shopify B2B company/multi-user accounts, customer-specific wholesale catalogs, and automated restock notifications require Shopify-native B2B/subscription capabilities or an app/backend integration. V13 provides the storefront UI and integration points without faking those backend capabilities.
