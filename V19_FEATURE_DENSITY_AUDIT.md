# V19 Feature Density Audit

## Keep prominent
- Search
- Categories
- Add to cart
- Cart / checkout path
- Quick Order for farm-volume use

## Keep secondary
- Wishlist
- Farm Lists
- Compare
- Brand browsing
- Saved Cart

## V19 reductions
- Compare is hidden from mobile product-card chrome; it remains available on the product page and compare page.
- Duplicate product-page service explanations were removed because the variant selector and Farm List action already explain themselves.
- Technical “preview catalog” wording was removed from normal browsing surfaces.
- Mobile touch targets and sticky purchase hierarchy were tightened so core buying actions win over utility actions.

## Do not add before real data/backend
- Loyalty points
- Customer tiers
- Live reviews
- Real shipping promises
- Real payment claims
- Fake ratings or fake stock urgency
