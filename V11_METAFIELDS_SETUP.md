# GOLDEN ROOTS V11 — Metafield Map

Create only the metafields relevant to your catalog. Empty fields are automatically hidden.

## Product metafields (`custom`)
- `badge` — Single line text
- `package_size` — Single line text
- `seed_count` — Single line text
- `variety` — Single line text
- `hybrid` — Single line text
- `npk_formula` — Single line text
- `weight` — Single line text
- `formulation` — Single line text
- `active_ingredient` — Single line text
- `volume` — Single line text
- `model` — Single line text
- `power` — Single line text
- `warranty` — Single line text
- `bundle_products` — List of product references
- `specifications` — Rich text (already supported)

## Collection metafields (`custom`)
- `featured_products` — List of product references

These fields intentionally avoid the removed product-page blocks: why this product, used for, suitable crops, agricultural problem, stage of use, and method of use.
